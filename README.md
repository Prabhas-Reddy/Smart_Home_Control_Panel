Smart Home Control Panel

Project Overview:
The Smart Home Control Panel is an interactive web application built with React (via CDN) that allows users to monitor and control smart devices across different rooms. The app features a modern UI with glassmorphism design, dynamic greetings, real-time weather info, and easy device toggling.

Features:
1. Dynamic greeting based on system time (Good Morning / Afternoon / Evening).
2. Live weather information using a free API.
3. Rooms displayed as cards with total devices and number of active devices.
4. Devices displayed as interactive sub-cards with ON/OFF toggles.
5. Modern, next-level UI with glassmorphism and smooth hover effects.
6. All cards (rooms & devices) centered for a visually appealing layout.

Technology Stack:
1. HTML, CSS, JavaScript
2. React (via CDN, no build tools required)
3. Open-Meteo API (for live weather)
